# 나온집 쇼츠 EP.01 — "브릿지야, 이거 돈 되냐?"

## 제목

- 메인: 브릿지야, 이거 돈 되냐? (AI랑 맛집앱 만든 결말)
- 대체: 방송맛집 앱 만들다 포트폴리오가 된 사연

## 캐릭터

- **대표**: 부산 INTJ 사업가. "돈 되나?"가 입버릇. 의심 많지만 실행 빠름.
- **브릿지**: AI 실장. 현실 체크 담당. 담백·직설.

## 30초 대본 (타임코드)

- (0-3s) 대표: "브릿지야, 부산 방송맛집 앱. 이거 돈 되나?"
- (3-7s) 브릿지: "솔직히요? 사람들 방송맛집만으론 신뢰 잘 안 합니다."
- (7-11s) 대표: "예약 기능 붙이까? 캐치테이블 이기게."
- (11-16s) 브릿지: "1인이서 예약 인프라요? ROI 안 나옵니다."
- (16-20s) 대표: "…그라믄 이거 다 버리나."
- (20-26s) 브릿지: "아뇨. 사업화 말고 **포트폴리오**로 바꾸죠. 출처를 같이 보여주고, 만든 건 다 남깁니다."
- (26-30s) (화면: 상세 출처 칩 + '추가 출처' + '출처 보기') 대표: "…돈은 안 됐는데, 능력은 남았네."

## 화면 구성 (컷)

1. (0-7s) 대표 클로즈업 + 폰에 홈 화면(나온집)
2. (7-16s) 분할: 캐치테이블 로고 위에 ❌ / "예약 인프라 필요" 자막
3. (16-20s) 대표 한숨 + 어두운 톤
4. (20-26s) 밝은 전환 — 상세페이지 스크롤(출처 칩 → 추가 출처 → 출처 보기 링크 강조 줌)
5. (26-30s) Admin 신뢰 출처 입력 화면 살짝 + 엔드카드("사람=판단 / AI=실행")

## 자막 (번인)

- "방송맛집? 사람들은 신뢰 안 한대요"
- "1인이서 예약 플랫폼과 정면승부? ROI ❌"
- "사업화 말고 → 포트폴리오로"
- "출처와 함께 보여준다 (방송·유튜브·미쉐린·비짓부산)"
- "돈은 안 됐다. 근데 운영 능력은 남았다."
- 엔드카드: "사람 = 판단/방향 · AI = 실행/검증/문서"

## 효과음 / 전환

- 0s: "톡" 알림음(질문 던지는 느낌)
- 3-7s: 살짝 '뿅' 빠지는 효과(팩폭)
- 16-20s: 로우톤 'shh'(고민 구간)
- 20s: 밝은 'whoosh' 전환(방향 전환 포인트 — 여기가 훅)
- 26-30s: 도장 찍는 'kachunk'(엔드카드)

## 썸네일 문구 후보

1. "이거 돈 되냐?" (대표 얼굴 + 폰)
2. AI랑 맛집앱 만든 결말
3. 사업화 ❌ → 포트폴리오 ✅
4. "돈은 안 됐지만…"
