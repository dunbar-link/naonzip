# 나온집 — 1인 + AI로 만든 부산 맛집 큐레이션 (Final One-pager)

## 한 줄 소개

부산에서 **방송·유튜브·가이드에 나온 맛집을 "출처와 함께" 빠르게 고르는** 모바일 웹.
기획자 1인이 AI(Claude Code)와 함께 설계·구현·운영·문서화까지 끝냈다.

## 만든 것

- 공개 서비스: 홈 · 목록 · 상세 · 검색 · 지도 · 저장 + 지역/프로그램/크리에이터/카테고리 랜딩
- 운영자 Admin CMS: 후보 수집→검토→변환→게시, 편집, 신뢰 출처 관리, 제보 처리
- 데이터·신뢰 출처 파이프라인: 후보 큐 → 지오코딩 → 공개 게이트 / 방송·유튜브 + 가이드·로컬 출처 칩
- 규모: 공개 91곳 · 정적 223페이지 · commit 130+개

## AI(Claude Code)가 수행한 것

데이터 후보 수집 · DB 스키마/RLS/마이그레이션 · UI · Admin CMS · SEO(JSON-LD/OG/ISR) ·
이미지 운영 스크립트 · 신뢰 출처 구조·입력·표시·리포트 · 매 단계 타입체크/빌드/노출 검증·문서화

## 사람이 판단한 것

문제 정의와 우선순위 · 방향 전환(사업화 → 포트폴리오) · 저작권/정책 라인 ·
"무엇을 안 할지"(예약·광고·전국확장) 선택 · 최종 승인

## 핵심 기술/구조

Next.js 16 App Router · React 19 · Tailwind v4 · TypeScript · Supabase(Postgres + RLS) ·
Kakao Map · Vercel(ISR). restaurants/appearances/candidate_queue/reports/**trust_sources**(RLS) 구조.

## 검증 결과

- 매 Phase `tsc` + `build`(정적 223페이지) 통과, 프리렌더 HTML로 실제 노출까지 확인
- 신뢰 출처: 설계 → 적용 → 입력 → 표시 → 링크 → 실데이터까지 끝단 동작 검증
- 모든 변경을 작은 단위로 쪼개 문서/리포트로 감사 추적 가능

## 한계 (솔직하게)

예약/웨이팅 없음 · 식당 수익모델 약함 · 실제 트래픽·수익 미검증 ·
이미지/출처 저작권 지속 관리 필요 · 신뢰 출처 데이터는 아직 소량

## 포트폴리오 가치

사람=판단/방향, AI=실행/검증/문서의 협업을 그대로 보여준다.
