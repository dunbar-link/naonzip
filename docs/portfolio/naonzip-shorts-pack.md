# 나온집 유튜브 쇼츠/릴스 소재 패키지

## 캐릭터 톤

- **대표(사용자)**: 부산 INTJ 사업가. 입버릇은 "이거 돈 되나?". 의심은 많지만 실행은 누구보다 빠름.
- **브릿지(AI 실장)**: 현실 체크 담당. 팩트로 김 빼지만 일은 끝까지 해줌. 담백·직설.

> 톤 주의: 재미는 살리되 **수익/시장검증 과장 금지.** "돈은 안 됐다"가 오히려 솔직 개그 포인트.

---

## 쇼츠 제목 후보 10개

1. "브릿지야, 이거 돈 되나?" — AI랑 맛집앱 만든 썰
2. 부산 사장님이 AI한테 맛집앱 시킨 결과
3. 방송맛집 앱 만들다가 포트폴리오가 된 사연
4. "사람들은 방송맛집 신뢰 안 한대요" (팩폭)
5. AI가 DB부터 Admin까지 다 만들면 생기는 일
6. 돈은 안 됐지만 운영 능력은 남았다
7. 1인 + AI로 서비스 하나 끝까지 만들어봄
8. 사장님: 사업화 / 브릿지: …포트폴리오로 가시죠
9. AI한테 "미쉐린 출처 붙여줘" 했더니 생긴 일
10. 망한 거 아님. 방향 바꾼 거임.

## 30초 대본 3개

### 30초 #1 — "돈 되나?"

- (0-3s) 대표: "브릿지야, 부산 방송맛집 앱. 이거 돈 되나?"
- (3-8s) 브릿지: "솔직히요? 사람들 방송맛집만으론 신뢰 잘 안 합니다."
- (8-15s) 대표: "…그라믄 우짜노."
- (15-22s) 브릿지: "출처를 같이 보여주죠. 미쉐린·비짓부산까지 '어디서 봤는지'."
- (22-27s) (화면: 상세페이지 출처 칩 + '추가 출처' + '출처 보기')
- (27-30s) 대표: "돈은?" 브릿지: "그건 다음 영상에서요."

### 30초 #2 — "사업화 말고"

- (0-4s) 대표: "예약 기능 붙이자. 캐치테이블 이기자."
- (4-10s) 브릿지: "1인이서 예약 인프라요? ROI 안 나옵니다."
- (10-16s) 대표: "그럼 이거 다 버리나?"
- (16-24s) 브릿지: "아뇨. 사업화 말고 **포트폴리오**로 바꾸죠. 만든 건 다 남습니다."
- (24-30s) (화면: case study 문서 + commit 129 + 정적 223페이지) 대표: "…오케이, 그건 말 되네."

### 30초 #3 — "AI가 다 했네"

- (0-3s) 대표: "니가 뭐까지 했노?"
- (3-12s) 브릿지(빠르게): "DB 스키마, RLS, Admin CMS, SEO, 이미지 운영, 신뢰 출처 구조까지."
- (12-18s) 대표: "그라믄 내는 뭐 했노?"
- (18-26s) 브릿지: "판단하고, 방향 틀고, '하지 말 것'을 정하셨죠. 그게 제일 중요합니다."
- (26-30s) 대표: "…인정." (자막: 사람=판단 / AI=실행·검증·문서)

## 45초 대본 2개

### 45초 #1 — 처음부터 끝까지 (요약 스토리)

- (0-5s) 대표: "부산 방송맛집 앱 하자. 브릿지, 가자."
- (5-12s) (몽타주: 홈/목록/상세/지도/검색 화면) 자막: "골격은 며칠 만에."
- (12-20s) 대표: "근데 사람들 반응이 영…" 브릿지: "방송맛집은 신뢰가 약해요. 예약도 없고요."
- (20-30s) 브릿지: "방향 둘 다 틉시다. 제품은 '출처 기반 큐레이션', 사업은 '포트폴리오'."
- (30-38s) (몽타주: Admin CMS, 신뢰 출처 입력, 상세 추가 출처, 리포트 문서)
- (38-43s) 자막: "공개 91곳 · 정적 223페이지 · commit 129개"
- (43-45s) 대표: "돈은 안 됐다. 근데 능력은 남았네." 브릿지: "그게 핵심입니다."

### 45초 #2 — "하지 말 것"의 힘

- (0-5s) 대표: "전국 확장하자. 광고 붙이자. 이미지 다 긁어오자."
- (5-14s) 브릿지: "셋 다 스톱입니다. 전국=자원, 광고=수익모델 약함, 이미지=저작권."
- (14-22s) 대표: "그럼 할 수 있는 건 뭔데?"
- (22-32s) 브릿지: "운영자가 확인한 출처만 안전하게. 미쉐린은 자동 확인이 막혀서 **비공개로 넣어두고**
  대표가 확인하면 공개." (화면: staged 처리)
- (32-40s) 대표: "조심성 한번 지독하네."
- (40-45s) 브릿지: "포트폴리오의 핵심은 '무리 안 한 흔적'이에요." (자막: 안전장치 = 실력)
