# 나온집 신뢰데이터·프로필 개선 마스터 플랜 R1

- Owner scope: 310 · 나온집
- 기준일: 2026-10-05 KST
- 목적: 기존 부산 맛집 프로필을 "방송·가이드·지도 데이터가 있다"는 표현이 아니라, 사용자가 원천과 확인일을 추적할 수 있는 사실 기반 프로필로 유지한다.

## 원칙

1. 신뢰 출처는 순위·맛·방문·AI 인용·매출을 보장하는 배지가 아니다.
2. 공개 출처에는 확인일이 필요하다. 방송·유튜브는 회차/영상 제목이 있으면 URL 없이도 공개할 수 있으나, 화면에 원천 링크 미등록을 표시한다. 그 밖의 출처는 URL과 확인일이 필요하다.
3. 기존 운영 DB의 대량 보정·자동 공개·출처 본문 복제는 하지 않는다. 원천별 사실 확인이 선행되어야 한다.
4. 공개 프로필·구조화 데이터·검색 결과·실제 검색/사업 성과는 별도 상태로 기록한다.

## 실행 순서

### Phase 1 — 입력 품질 게이트 (이번 실행)

- 공개 출처 추가·수정 시 확인일을 서버와 화면 양쪽에서 요구한다. 방송·유튜브는 회차/영상 제목이 있으면 URL 없이도 링크 미등록 상태로 공개할 수 있다.
- 비공개 초안은 근거 수집을 위해 URL/확인일 없이 저장할 수 있다.
- 완료 조건: 신규 공개 출처가 근거 없는 라벨만으로 저장되지 않는다.

**완료:** 관리자 클라이언트·서버 양쪽에 확인일 검증을 적용했다. 방송·유튜브 링크 미등록은 화면에 상태를 표시하며, 가이드·운영자 확인 등은 URL/확인일 없이는 공개되지 않는다. 비공개 초안은 계속 허용한다.

### Phase 2 — 증거 보완 큐 (이번 실행)

- `npm run evidence:audit`으로 공개 프로필별 URL·확인일·링크 미등록 상태를 추적한다.
- 완료 조건: 18 URL 미입력 항목을 방송·유튜브 링크 미등록으로 별도 분리한다.

**완료:** `reports/profile-evidence/profile-evidence-audit-latest.{md,csv}`에 18건을 링크 미등록으로 분리했다. URL·확인일이 모두 없던 공개 `운영자 확인` 1건은 삭제하지 않고 비공개 초안으로 전환했다. 해당 프로필의 기존 유튜브 영상 근거는 유지한다.

### Phase 3 — 기존 데이터 보완 (근거 확보 때만)

- 각 출처 URL을 원천에서 열어 식당 동일성·현행성·사실 표현을 확인한다.
- 확인된 항목만 운영자가 URL을 보완한다. 방송·유튜브의 기존 공개 메타데이터는 링크 미등록 상태를 표시하며 유지하고, 막힌 원천은 URL 미확인으로 둔다.
- 완료 조건: 임의의 일괄 DB 업데이트가 아닌, 항목별 원천 근거와 변경 후 공개 페이지 readback이 있다.

**진행:** 근거 없는 공개 `운영자 확인` 1건을 비공개로 전환하고 PC·390px 공개 프로필에서 해당 라벨이 노출되지 않음을 확인했다. 우체국 가이드 40건은 공식 PDF 88쪽에서 각 식당의 이름·DB 주소를 대조해 40/40 일치했고, 공식 안내 URL·확인일을 공개 출처에 반영했다. 페이지별 증거는 `postoffice-2026-guide-verification.csv`에 보존한다. 방송·유튜브 18건은 기존 공개 노출을 유지하고, 상세페이지에 원천 링크 미등록을 표시한다. 링크가 추가될 때도 프로그램명 일치만으로 원천 공식성·식당 동일성이 자동 증명되지는 않는다.

### Phase 4 — 운영 검수

- `quality:audit`, `evidence:audit`, 상세 프로필의 원천 링크/JSON-LD, PC·390px 흐름을 확인한다.
- 완료 조건: 코드 회귀와 공개 노출 오류가 없고, 새 보완 데이터의 출처 링크가 실제 열리는 것을 확인한다.

**완료 — 2026-10-05 19:33 KST:** 대장의 직접 승인 뒤 `259fb1aaae55110b3e983b86c9c51972fac4dc3f`까지의 9개 신뢰 프로필 범위 커밋을 `origin/master`에 정상 반영했다. 공개 readback은 `https://naonzip.vercel.app/restaurants/saengsaeng-sasang-jurye-suyuk-kalguksu`에서 PC와 390px 모두 `원천 링크 미등록` 표시, 가로 넘침 없음, 콘솔 오류 없음을 확인했다. `https://naonzip.vercel.app/restaurants/2tv-haeundae-sundori-boribap`의 KBS 공식 링크(`https://iaudience.kbs.co.kr/broadcast/11290`)도 유지됨을 확인했다.

**빌드 증거 한계:** 권한 환경에서 Next build의 최종 `next-build`·`telemetry-flush` trace와 산출물은 확인했지만, 실행 도구가 쉘 종료코드를 반환하지 않아 `BUILD_EXIT_UNAVAILABLE`로 보존한다. 이는 공개 페이지 readback 성공이나 품질감사 결론을 대체하지 않는다.

**Kakao 감사 한계:** 전체 Kakao 품질감사는 140곳을 순차 조회한다. 이번 실행은 100번째 완료 표식 뒤 실행 결과가 종료코드 없이 반환되어 140곳 전체 PASS/FAIL을 확정하지 못했다. 원인은 실행 시간 제한일 가능성이 있으나 확정하지 않았다. 완료된 100건을 재조회하지 않도록 감사 도구에 범위 실행(`--offset`, `--limit`)을 추가하며, 마지막 40건만 별도 완료 확인한다. 범위별 결과는 전체 PASS를 대체하지 않는다.
