# 나온집 신뢰데이터·프로필 개선 마스터 플랜 R1

- Owner scope: 310 · 나온집
- 기준일: 2026-10-05 KST
- 목적: 기존 부산 맛집 프로필을 "방송·가이드·지도 데이터가 있다"는 표현이 아니라, 사용자가 원천과 확인일을 추적할 수 있는 사실 기반 프로필로 유지한다.

## 원칙

1. 신뢰 출처는 순위·맛·방문·AI 인용·매출을 보장하는 배지가 아니다.
2. 공개 출처에는 원천 URL과 확인일이 필요하다. 하나라도 불명확하면 비공개 초안 또는 보완 큐다.
3. 기존 운영 DB의 대량 보정·자동 공개·출처 본문 복제는 하지 않는다. 원천별 사실 확인이 선행되어야 한다.
4. 공개 프로필·구조화 데이터·검색 결과·실제 검색/사업 성과는 별도 상태로 기록한다.

## 실행 순서

### Phase 1 — 입력 품질 게이트 (이번 실행)

- 공개 출처 추가·수정 시 URL과 확인일을 서버와 화면 양쪽에서 요구한다.
- 비공개 초안은 근거 수집을 위해 URL/확인일 없이 저장할 수 있다.
- 완료 조건: 신규 공개 출처가 근거 없는 라벨만으로 저장되지 않는다.

**완료:** 관리자 클라이언트·서버 양쪽에 URL/확인일 검증을 적용했다. 비공개 초안은 계속 허용한다.

### Phase 2 — 증거 보완 큐 (이번 실행)

- `npm run evidence:audit`으로 공개 프로필별 URL·확인일 완결성을 추적한다.
- 완료 조건: 58 URL 미입력 항목을 식당·출처 단위로 확인 가능한 큐로 분리한다.

**완료:** `reports/profile-evidence/profile-evidence-audit-latest.{md,csv}`에 58건을 만들었다. URL·확인일이 모두 없던 공개 `운영자 확인` 1건은 삭제하지 않고 비공개 초안으로 전환했다. 해당 프로필의 기존 유튜브 영상 근거는 유지한다.

### 보완 큐의 사실 상태

| 묶음 | 건수 | 현재 결론 | 처리 원칙 |
| --- | ---: | --- | --- |
| 우체국 추천 맛집가이드 2026 | 40 | 발행처와 로컬 원본은 확인됐으나 공식 PDF 게시 URL은 `OFFICIAL_URL_REVIEW` | 임의 공식 URL을 넣지 않고 공식 게시 경로 확인 대기 |
| 방송·유튜브 출처 | 18 | 프로그램/크리에이터 단위의 원천 URL이 각기 필요 | 방송 회차·영상·기사의 식당 동일성을 개별 확인 후만 보완 |

### Phase 3 — 기존 데이터 보완 (근거 확보 때만)

- 각 출처 URL을 원천에서 열어 식당 동일성·현행성·사실 표현을 확인한다.
- 확인된 항목만 운영자가 공개 출처로 보완한다. 막힌/동일성 불명은 비공개 유지 또는 `UNKNOWN`으로 둔다.
- 완료 조건: 임의의 일괄 DB 업데이트가 아닌, 항목별 원천 근거와 변경 후 공개 페이지 readback이 있다.

**진행:** 근거 없는 공개 `운영자 확인` 1건을 비공개로 전환하고 PC·390px 공개 프로필에서 해당 라벨이 노출되지 않음을 확인했다. 공개 출처가 없는 방송 프로필은 유효한 `video_url`이 있을 때 이를 별도 사용자 추적 근거로 인정하며, 출처 라벨을 중복 공개하지 않는다.

### Phase 4 — 운영 검수

- `quality:audit`, `evidence:audit`, 상세 프로필의 원천 링크/JSON-LD, PC·390px 흐름을 확인한다.
- 완료 조건: 코드 회귀와 공개 노출 오류가 없고, 새 보완 데이터의 출처 링크가 실제 열리는 것을 확인한다.
