## 4. 기타 보완 메모

- **kakao_map_url 빈값(13곳 전부)**: 공개 차단 아님. `ShareButtons.buildKakaoUrl` 가 좌표로 `map.kakao.com/link` 를 자동 생성하므로 카카오맵 버튼은 정상 동작. 정확한 place_url 을 채우고 싶으면 Admin 편집/quick-register "주소로 좌표 찾기"의 place_url 로 보강(선택).
- **weak 중복(공유 기사/영상 URL)**: 왔다식당↔연합횟집(국제뉴스 3148274), 여송제↔수타혜미칼국수(국제뉴스 3159804), 백일평냉↔담미옥(이투데이 281540). 모두 한 기사/영상에 여러 식당이 함께 소개된 케이스로 식당명·주소가 달라 실제 중복 아님. 공개 가능. (선택) 개별 영상/플레이스 URL 로 video_url 교체 시 weak 표시 해소.
- **좌표**: 13곳 전부 부산 하드범위 + 권역 advisory 통과. 공개 전환 금지 사유 없음.
- **appearance**: 13곳 전부 1건 보유(source_type·source_title·video_url 충족). 누락 없음.
