# 나온집 콘텐츠-장소 플랫폼 마스터 플랜 R1

- Owner scope: 310 · 나온집
- 기준일: 2026-10-05 KST
- 북극성: 방송·유튜브에서 본 부산 식당을 원천·회차·장소·방문 행동으로 연결하는 소비자 발견 플랫폼을 만든다.

## 하지 않을 것

- 지도·리뷰·웨이팅·예약 서비스를 복제하지 않는다.
- 출처만으로 맛·순위·영업 상태를 보장하지 않는다.
- AI 노출·검색 순위·매출을 약속하거나, 광고 상품을 소비자 가치보다 먼저 만들지 않는다.

## 제품 루프

`프로그램/크리에이터/회차 검색 → 출연 식당 확인 → 상세 확인 → 저장·지도 이동·공유`

플랫폼의 독자 자산은 화면이 아니라 `출처 ↔ 출연 기록 ↔ 식당 ↔ 방문 행동` 연결이다. 기존 `restaurant_appearances`와 공개 프로필을 사용하고, 새 DB·유료 API·외부 콘텐츠 복제를 만들지 않는다.

## Phase 1 — 콘텐츠에서 장소 찾기

- `/from` 허브에서 프로그램·크리에이터별 출연 식당으로 진입한다.
- 프로그램·크리에이터 페이지를 회차/영상 단위 출연 묶음으로 표시한다.
- 등록된 영상·페이지 링크가 있으면 해당 링크를 열고, 없으면 `출처 링크 미등록`을 명시한다. 등록 링크 자체가 공식 원천임을 자동으로 뜻하지 않는다.
- 완료 조건: 사용자가 "어디서 봤지?"에서 출처 → 식당 → 기존 저장·지도 이동 흐름을 한 번에 완료할 수 있다.

### 공개 반영·실제 화면 검수 — 2026-10-05

- 공개 revision: `d2d17687b42ab53c5b6ad4c5c499daf20691fff6`.
- 공개 `/from`에서 출처 허브와 17개 출처 카드가 보이고, `/program/live-info`에서 출처 묶음 → 식당 상세 이동 흐름이 동작함을 PC와 390px에서 확인했다.
- 등록 URL이 있는 묶음은 `등록된 관련 링크`, URL이 없는 묶음은 `출처 링크 미등록`으로 표시한다. 이전의 `공식 원천` 표현은 제거했다.
- 해당 공개 화면에서 콘솔 오류와 가로 넘침은 관측되지 않았다. 단위 검증 `content:unit`은 5/5, 타입 검사·빌드는 통과했다. lint는 오류 0건과 기존 경고 8건을 분리해 기록한다.
- 000 검수 수신: Phase 1의 안전 교정·공개 단계는 완료로 보고되었고, 유입·저장·지도 이동·공유의 사업 성과는 별도 `NOT_MEASURED`로 유지한다.

## Phase 2 — 데이터 밀도

- 공식 출처 링크·회차·방영일이 확인된 출연 기록을 우선 보강한다.
- 링크 없는 공개 기록은 유지하되, 강한 원천 기반 랜딩의 대표 근거로 승격하지 않는다.
- 완료 조건: 확장 전에 원천 확인 상태와 링크 미등록 상태가 구분된다.

### 현재 분류 감사 — 2026-10-05

- 공개 프로필 140개를 읽기 전용으로 대조했다. 출연 기록은 100행, 등록된 출연 링크는 73행, 공개 미디어 신뢰 출처 링크는 66행, 링크 없는 공개 미디어 신뢰 출처는 18행이다.
- 출연 링크와 미디어 신뢰 출처 링크의 정확 URL 일치는 50건뿐이다. 따라서 링크가 있다는 이유만으로 강한 공식 원천 랜딩으로 자동 승격할 수 없다.
- 기존 검증 등록부의 방송·유튜브 18건은 공식 도메인 검색에서 `OFFICIAL_SEARCH_NO_RESULT`이며, 이는 방송 사실 부정이나 원천 부재의 확정 판정이 아니다. 링크 없는 상태는 그대로 보존한다.
- 우체국 가이드 40건의 공식 PDF 근거는 장소 가이드 근거이며 방송·유튜브 원천 랜딩 근거로 혼용하지 않는다. 별도 수동 KBS 공식 링크는 해당 식당 프로필의 명시 근거로만 유지한다.
- 결론: 현재 `등록된 관련 링크`와 `출처 링크 미등록`의 구분은 근거에 맞다. 자동 승격·18건 재탐색·DB 반영은 하지 않았다.

## Phase 3 — 소비자 행동 판단

- Search Console의 출처명·회차명 유입과, 저장·지도 이동·공유 행동을 분리해 관측한다.
- 일반 지역/메뉴 검색만 발생하고 출처 탐색이 선택 이유가 아니면 플랫폼 확장을 중단하거나 방향을 재평가한다.
- 현재 이 성과 데이터는 `NOT_MEASURED`다.

### 현재 관측 기반선 — 2026-10-05

- 기존 Search Console 정본의 일치 코호트 진단은 이전 스냅샷이며, 이번 범위에서 현재 원천은 `SOURCE_UNAVAILABLE`/`STALE`이다. 이를 0 유입 또는 부정적 결과로 해석하지 않는다.
- 현재 공개 앱에는 저장·공유·지도 이동의 사용자 기능은 있으나, 이 행동을 서버에서 집계하는 신규 분석 파이프라인은 없다. 실제 행동 건수는 `NOT_MEASURED`다.
- 재개 조건: 기존 승인된 Search Console 또는 행동 관측 원천이 다시 접근 가능해지고, 이번 공개 후 충분한 자연 관측 기간의 동일 조건 비교가 가능할 때만 유입·행동을 판단한다. 새 계정·분석 도구·DB·유료 호출은 만들지 않는다.

## Phase 4 — 수익화는 자연 유입 뒤

- 충분한 소비자 유입 뒤 식당이 공식 정보 보완·외국인 방문 정보·출처 정정을 문의할 때만 관리 상품을 검토한다.
- 업체 과금·광고 노출량 판매는 Phase 3의 실제 행동 근거 전에는 만들지 않는다.
